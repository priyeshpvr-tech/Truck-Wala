# Truck Wala — Retro Music Experience

Static HTML/CSS/JS website inspired by the supplied Salon Wala reference architecture.

- Full-screen glass player UI
- Hidden official YouTube IFrame player
- YouTube playlist ID + YouTube Data API v3 loading
- Searchable Up Next playlist overlay
- Previous / play-pause / next / loop / volume / seek
- YouTube errors stay on the current track instead of automatically skipping
- Track automatically advances only when the current video actually ends
- localStorage remembers playlist, API key, volume and current position

For public deployment, use a browser/referrer-restricted YouTube Data API key and restrict it to YouTube Data API v3.
